# State Transition Rules

| From | Allowed to |
|---|---|
| DRAFT | ANALYZING, CANCELLED |
| ANALYZING | NEEDS_CLARIFICATION, READY_FOR_APPROVAL, FAILED, CANCELLED |
| NEEDS_CLARIFICATION | ANALYZING, CANCELLED |
| READY_FOR_APPROVAL | APPROVED, ANALYZING, CANCELLED |
| APPROVED | EXECUTING, CANCELLED |
| EXECUTING | READY, NEEDS_FIX, FAILED, CANCELLED |
| NEEDS_FIX | EXECUTING, READY_FOR_APPROVAL, CANCELLED |
| READY | READY_FOR_APPROVAL, CANCELLED |
| FAILED | ANALYZING, EXECUTING, CANCELLED |
| CANCELLED | terminal |

Approval stages are exactly `BRIEF_PENDING`, `TRANSFORMATION_PENDING`, `COMPLETE`. Invalid transitions produce `STATE_INVALID_TRANSITION` without a partial state change.
