## Current decision and confirmed conflict

CR-P2-001 phase-scoped historical P1-T30 for P2 while adding a full-tree P2-T40 audit. In the validated P2 runtime, `tests/p2/test_p2.py::test_T40_scope_dependencies` checks fixed application source paths, imports/calls/definitions, frozen P1 code/migrations, project dependencies and changed paths. Authorized P3 modules/workflow/API and Streamlit integration would otherwise be rejected by the historical P2 exact app inventory.

## APPROVED change — narrow test-boundary amendment only

1. **Retain P2-T40** test ID and its relevant negative assertions for explicit frozen P1+P2 modules and approved dependencies; phase-scope its historical application inventory so authorized P3 modules are not a false regression.
2. Authorize only P3-specific module paths and the necessary approved Streamlit integration. No general exemption for LLM, Telegram, network/API/URL/JSON ingestion, browser automation, workers/queues, arbitrary code execution, ORM, new DB schema/migrations, P4–P6 engine/export/QA.
3. **Require P3-T51 full-application audit** against the complete explicitly reviewed P0/P1/P2/P3 inventory, dependency and migration allowlists, source surface hashes and negative probes for forbidden P4+, services, integrations and changed P1/P2 runtime.
4. Commit a versioned P2 acceptance/traceability amendment for the phase-scoped interpretation. Preserve the original approved P2 Pack v1.0 and validated P0/P1 normative docs/runtime unchanged.
5. Actually rerun P1 42/42, P2 54/54, P3 52/52 tests with no skips/xfail or hiding failures; publish JUnit, source/test change audit and validation report.

## Business, scope and risk

- Enables the minimal human-driven Brief/Spec and two Approval workflow without extending product scope.
- Risk: an overly narrow P2-T40 may miss an unauthorized integration. Mitigation is immutable P1+P2 coverage **plus** the new whole-tree P3-T51 with negative probes.
- Refusal would block the simultaneous P3 implementation and required 54/54 P2 regression under the current P2-T40 test.

**APPROVED only as future corrective test work, not implemented by this decision.** No P3 production code may begin until separately authorized. This CR does not close P3 Gate B, alter P0 statuses/approval semantics or authorize P4.
